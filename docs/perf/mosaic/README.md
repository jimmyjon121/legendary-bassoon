# Mosaic Gate 1 Profile Artifacts

This directory stores Phase 3 Gate 1 measurement artifacts. Files are generated by `scripts/mosaic-profile-*.js`, consumed by `scripts/mosaic-simulate.js`, and summarized by `scripts/mosaic-gate1-decide.js`.

## Device Profile Schema

```json
{
  "schemaVersion": 1,
  "device": "rtx",
  "model": "qwen2.5-coder:14b",
  "createdAt": "2026-04-25T00:00:00.000Z",
  "hardware": {
    "name": "RTX 5050 Laptop",
    "memoryBytes": 8589934592
  },
  "prefillMsPerLayer": [1.0],
  "decodeMsPerLayer": [0.7],
  "memBytes": [225000000],
  "throughputTokensPerSecond": 32.0,
  "runMeta": {
    "source": "live",
    "samples": [],
    "fallbackReason": null,
    "error": null
  }
}
```

Required fields:

- `schemaVersion`: currently `1`.
- `device`: one of `rtx`, `arc`, `npu`, `cpu`, `rebar`.
- `model`: profiled model id.
- `prefillMsPerLayer`: estimated prefill milliseconds per model layer.
- `decodeMsPerLayer`: estimated decode milliseconds per model layer.
- `memBytes`: estimated resident bytes per model layer.
- `throughputTokensPerSecond`: observed or inferred decode throughput.
- `runMeta.source`: `live`, `fallback`, `synthetic`, or `projection`.

## ReBAR Transfer Profile

`profile-rebar.json` uses the same envelope and stores transfer-specific fields in `runMeta`:

```json
{
  "device": "rebar",
  "runMeta": {
    "bandwidthGBps": 16.0,
    "method": "nvidia-smi-estimate",
    "source": "live"
  }
}
```

## Decision Artifacts

- `sim-14b.json`: simulator output for the mandatory 14B target.
- `sim-30b.json`: simulator output for the best-effort 30B target when enough profile data exists.
- `decision.json`: machine-readable PASS/FAIL result from `mosaic-gate1-decide.js`.

`docs/perf/mosaic-gate1.md` is the human-readable canonical decision report.
